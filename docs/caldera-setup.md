# MITRE CALDERA Setup

MITRE CALDERA was deployed on a dedicated Linux virtual machine.

## Installation Overview
- Operating System: Kali Linux / Ubuntu
- CALDERA version: Community Edition
- Plugins used: Stockpile

## Deployment Steps
1. Clone the official MITRE CALDERA repository
2. Install required dependencies
3. Start the CALDERA server
4. Access the web interface via browser

The CALDERA server is used to simulate adversary behavior
against machines in the target network.
